# Sword Art Offline

Official Windows player downloads for Sword Art Offline.

Download **SAO-Launcher-Windows-x64.zip** from the [latest release](https://github.com/Cxrpss/sao-releases/releases/latest), extract the folder, and open **SAO Launcher.exe**.

The launcher installs Minecraft, NeoForge, Sword Art Offline and its companion mods. Sign in with your own Minecraft Java account in the Microsoft sign-in window. Future releases appear in the launcher and under **Updates** in the game. **Update & Restart** verifies the download, closes Minecraft, installs the update, and starts Minecraft again.

The public server has not been announced yet. Public builds do not offer single-player. This repository contains downloadable releases and does not contain the game's source code.

Your game files are in `%LOCALAPPDATA%\SwordArtOffline\minecraft\instances\sao\.minecraft`. The launcher's **Game folder** button opens them. Worlds and personal settings are preserved during updates. A failed update keeps its recovery journal and backups in `%LOCALAPPDATA%\SwordArtOffline`.

Windows x64 and an account that owns Minecraft Java Edition are required. The launcher includes Java. Minecraft installation and Microsoft account sign-in are provided by the unmodified [Prism Launcher](https://prismlauncher.org), downloaded from its official releases. Companion mods are downloaded from their authors; see the in-game mod credits.
